# 🎬 Netflix Movies Data Analysis

A data analysis project focused on exploring movie genres, popularity, audience votes, and release-year trends using Python and popular data analysis and visualization libraries.

---

## 📌 Project Overview

This project analyzes a movie dataset to discover interesting patterns and trends related to movies, including:

* Movie genres
* Popularity
* Audience votes
* Most and least popular movies
* Movie release years
* Genre distribution

The project demonstrates the use of **Python, NumPy, Pandas, Matplotlib, and Seaborn** for data cleaning, exploratory data analysis, and visualization.

---

## 🎯 Project Purpose

The purpose of this project is to analyze a movie dataset and explore patterns in genres, popularity, votes, and release years.

The project aims to transform raw movie data into meaningful insights through data cleaning, analysis, visualization, and interpretation.

---

## 🔎 Analysis Performed

The following questions were explored during the analysis:

1. What is the most frequent genre in the dataset?
2. Which genre has the highest popularity/votes?
3. Which movie has the highest popularity?
4. Which movie has the lowest popularity?
5. What genres are associated with the most and least popular movies?
6. Which year contains the highest number of movies?

---

## 📊 Key Insights

### 🎭 Most Frequent Genre

**Drama** was the most frequent genre in the dataset, appearing in more than **14%** of the movies across the dataset's genres.

### ⭐ Most Popular Genre

Drama also showed the highest presence among popular movies, accounting for more than **18.5%** of the popular movies in the analysis.

### 🕷️ Highest Popularity Movie

**Spider-Man: No Way Home** had the highest popularity in the dataset.

Its listed genres include:

* Adventure
* Science Fiction

### 🎬 Lowest Popularity Movie

**The United States, Thread** had the lowest popularity in the dataset.

Its listed genres include:

* Music
* Drama
* War
* Science Fiction
* History

### 📅 Year with Most Movies

**2020** had the highest number of movies in the dataset.

This project provided an opportunity to explore movie data and identify patterns in genres, popularity, audience votes, and release years.
